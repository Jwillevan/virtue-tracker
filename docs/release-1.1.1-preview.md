# Virtue Tracker 1.1.1 preview

Overview now lets you tap the existing status icon to mark an active task complete or incomplete for the selected day. The count and progress bar update immediately, and completion history is saved.

The task name does not open an editor on Overview. Adding, editing, active/inactive switching, reset and deletion stay on the Tasks tab/editor. The icon artwork, active-only filtering, fixed add button, and other behavior from 1.1.0 are retained.

This development preview uses the same local signing key as 1.1.0 and can be installed over that preview. Do not uninstall first.

Validation: 3 data/history tests and 3 Android emulator UI tests passed, including toggling completion on Overview, immediate progress updates and persistence. Android lint completed without errors. The new APK installed over preview 1.1.0 on the emulator.
